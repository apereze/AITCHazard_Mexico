# Contributing

This repository supports a doctoral research project and manuscript preparation. Contributions are welcome in the context of academic collaboration.

## Before Contributing

- Open an issue or contact the maintainer before adding substantial methods, datasets, or analysis workflows.
- Keep scientific assumptions explicit in documentation or code comments.
- Do not commit private files, raw climate archives, large generated outputs, or local machine paths.

## Repository Practices

- Use descriptive branch names and commit messages.
- Keep code modular and documented when code is added.
- Store lightweight, reproducible documentation in Git.
- Store large data and generated outputs outside Git, with provenance documented in `docs/data-governance.md`.
- Keep notebooks clear, restartable, and focused on one analysis question.

## Documentation Standards

- Document input datasets, coordinate conventions, temporal coverage, and units.
- Mark unresolved scientific decisions as open questions.
- Avoid presenting placeholders as completed workflows.
