# AITCHazard Mexico Project Context

Last updated from handoff context: 2026-06-04.

This document preserves the current scientific and technical decisions for the AITCHazard Mexico doctoral project. It is a cleaned repository version of the working context brief and should be updated when major design choices change.

## Project Summary

AITCHazard Mexico is a four-block tropical cyclone hazard workflow for Mexico and the surrounding region:

1. **Retrospective AIFS forecasting**: run retrospective forecasts with AIFS Single v2 for selected tropical cyclone cases.
2. **Precipitation downscaling**: downscale coarse AIFS precipitation to a target grid compatible with MSWEP.
3. **Wind hazard estimation**: estimate probabilistic wind hazard from the meteorological fields generated in Block 1.
4. **Hazard prediction**: combine hazard information to calculate a tropical cyclone hazard index for the study area.

## Domain and Time Design

- Latitude: `5N` to `35N`.
- Longitude: `130W` to `60W`.
- Longitude in 0-360 convention: `230E` to `300E`.
- Cases: tropical cyclone dates and times.
- Initialization frequency: every 6 hours.
- Forecast horizon: `t0` to `t+72 h`.
- Forecast output frequency: every 6 hours.
- Study period: `2000-2025`.

## Main Decisions

- Block 1 is retrospective and should use a hindcast-like workflow.
- Initial conditions should be reconstructed from MARS.
- AIFS Single v2 is the working target checkpoint and configuration.
- Block 1 official outputs should be NetCDF.
- The atmospheric column should be vertically rich where practical.
- The main precipitation variable for downstream use should be 6-hour interval precipitation, not only accumulated precipitation from initialization.

Recommended precipitation notation:

- `tp_raw` or `tp_accum_raw`: total accumulated precipitation from model output.
- `tp_6h`: 6-hour interval total precipitation.
- `cp_raw` or `cp_accum_raw`: accumulated convective precipitation.
- `cp_6h`: 6-hour interval convective precipitation.

## Block 1: Retrospective AIFS Forecasting

Objective: generate a regional, multi-variable meteorological dataset for tropical cyclone cases over `2000-2025`.

Subpipelines:

- Scheduler and case selection.
- Initial condition retrieval from MARS.
- AIFS Single v2 inference in a container/HPC environment.
- Temporal derivation and diagnostics.
- Regional extraction, quality control, and NetCDF storage.

Expected derived variables include `tp_6h`, `cp_6h`, and `ws10`, with optional shear, humidity, and wet-mask diagnostics.

## Block 2: Precipitation Downscaling

Objective: transform coarse AIFS precipitation into a high-resolution field aligned with the target observational product.

The preferred conceptual design is a two-stage architecture:

1. Lead-time-aware coarse bias correction.
2. Spatial super-resolution.

The main Block 2 precipitation predictor should be `tp_6h`; `cp_6h` is optional but recommended.

## Block 3: Wind Hazard Estimation

Objective: estimate probabilistic wind hazard from the meteorological backbone generated by Block 1 and tropical cyclone structure information.

Final variables and evaluation design remain open.

## Block 4: Hazard Index Prediction

Objective: combine precipitation and wind hazard information into a final tropical cyclone hazard index for Mexico and surrounding regions.

The final integration approach remains open and should be documented before implementation.

## Open Questions

- Exact target grid and resolution for Block 2.
- Deterministic versus probabilistic precipitation downscaling output.
- Full variable list for the wind hazard block.
- Evaluation framework for Blocks 3 and 4.
- Storage strategy if NetCDF output volume becomes too large.
- Case selection rules for tropical cyclones near Mexico.
